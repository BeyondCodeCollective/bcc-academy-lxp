## Notes

1. `/_vercel/insights/script.js` 404s and returns HTML on a non-Vercel host: console noise only when self hosted.
2. Mobile default view of the course schedule is List while desktop is Calendar (not a bug, noted so tests do not assume a view).

## Other findings from the passes

- Console errors across 21 pages x 2 viewports: only the Vercel insights script (MIME refused, 42) and blocked third party requests (88, our network block). No page errors.
- Horizontal overflow: none at 1440 or 412 wide.
- Limits: the stub does not scope rows per caller, so instructor scoping is verified at the UI level only. Student pages that need a Zoom, Blob or email dependency were not exercised.
- Disclosure: during early exploration, before the network block in `support/test.ts` existed, a browser run loaded Google Analytics and doubleclick scripts from the public pages. No credentials, no app data, no bccacademy.io, vercel.app or supabase.co host was contacted.
