01
Student-Facing

Student Experience

Every student gets a personalized, dynamic learning environment that adapts to their enrollment, progress, and program — from the moment they log in.

📊
Personalized Dashboard
The student's central hub dynamically adapts to their current state — surfacing the right next action whether that's completing onboarding, watching a welcome video, enrolling in a track, responding to a pending survey, or continuing their active week. No two students see the same dashboard.
Track Grid View
Visual grid of all enrolled tracks showing week-by-week progress, status icons, and direct links into the current week's content.
Progress Tracking
Real-time tracking of weeks completed versus total weeks per track. Progress is visible to both the student and their admins.
Self-Paced Track Mode
Tracks with pre-recorded content unlock weeks independently of a cohort start date, giving students flexible, on-demand access to sessions and materials.
Announcement System
Program admins can post announcements that appear prominently on the student dashboard, keeping the cohort informed between sessions.
Submission Workspace
Students respond to structured weekly prompts and attach project files or links. Each submission is stored and reviewable by the admin team.
Weekly Reflections
Per-week reflection prompts encourage students to synthesize their learning. Admins can view all reflections and track engagement over time.
AI Tutor Assistant
Each program can enable an AI-powered tutor with a custom system prompt tailored to that program's curriculum and voice. Tutor interactions count toward student engagement scores.
Workshops & Recordings Library
Students can access a library of Lunch & Learn recordings and past workshop sessions directly from the platform, extending learning beyond live sessions.
02
Content Management

Curriculum & Content

A rich, flexible curriculum engine supports everything from live cohort tracks to self-paced journeys, with granular control over when and how content is delivered.

Weekly Track Structure
Each track is organized into weeks. Every week contains a title, icon, description, learning objectives, session schedule, reflection prompts, submission prompts, and optional video recordings.
Drip-Release Content Gating
Weeks are locked until a configured date, automatically unlocking as the cohort progresses. Upcoming weeks are visible but clearly marked as coming soon.
Track Types
Supports both weekly (semester-style, cohort-paced) and single-event (one-off workshop or intensive) track formats within the same platform.
Track Phases
Tracks can be organized into learning phases — Foundation, Core, Workshop, Exit — creating a clear progression arc for students and program designers.
Prerequisite Enforcement
Track prerequisites ensure students complete foundational content before advancing. The platform enforces unlock rules automatically, no manual gatekeeping needed.
Office Hours Integration
Optional live office hours and drop-in sessions are listed directly on track landing pages, complete with date, time, title, and description for easy student discovery.
Session Video Recordings
Each week can link to one or more recorded session videos, making it easy for students who missed a live session to catch up at their own pace.
Flexible Submission Controls
Per-week configuration lets admins disable submissions for conceptual or discussion-only weeks — ensuring the submission experience stays relevant and purposeful.
03
Data Collection

Onboarding & Surveys

Built-in survey and intake systems collect student data at exactly the right moment — gating content access until required information is on file.

📋
Survey Gating System
Pending surveys appear on the student dashboard and can be configured as required — blocking access to track content until completed. This ensures demographic data, consent forms, and pre-program assessments are collected reliably without manual follow-up.
Intake Gates
Tracks can require students to complete a demographic or preference intake before accessing content. Multiple intake configurations can coexist across programs.
Flexible Question Types
Survey forms support radio buttons, multi-select checkboxes, and open-text fields — with per-question required/optional configuration.
Pre & Post Surveys
Programs can configure pre-program and post-program surveys to measure student outcomes, satisfaction, and goal achievement.
Public Survey Tracking
Non-authenticated survey responses are tracked separately, enabling outreach and interest capture from prospective students before they create an account.
Program-Specific Skipping
Survey visibility is configurable per program — students transferring from one program to another won't be prompted for surveys they've already completed.
Welcome Video Onboarding
Each program can configure a welcome video with the presenter's name, shown to students on first login to set context and build community before their first session.
04
Tracking & Metrics

Attendance & Engagement

A four-pillar engagement model gives program teams a quantitative, real-time view of how deeply each student is participating — going beyond simple attendance to capture the full learning journey.

Four-Pillar Engagement Scoring
Every student receives an engagement score built from four dimensions — attendance, project submissions, weekly reflections, and AI tutor usage — giving admins a single, at-a-glance signal of participation health.
Session-Level Attendance
Attendance is tracked at the individual session level — track, week, and session number — supporting programs that run multiple sessions in a single week.
Admin Attendance Marking
Instructors and admins mark attendance directly from the admin panel or via API. Records include who marked the attendance and when, creating a full audit trail.
Real-Time Engagement Scores
Engagement scores are calculated on-the-fly across all four pillars and displayed per student in the admin panel — no batch processing or exports needed.
Alumni Tracking
Students who complete a program can be moved to an alumni state, preserving their history and allowing the platform to distinguish active cohort students from graduates.
05
Operations

Administration & Analytics

A fully tab-gated admin panel gives instructors and program managers everything they need to run a cohort — from roster management to data export — without needing dev support.

🗂️
Tabbed Admin Interface
The admin panel is organized into focused tabs — Students, Attendance, Submissions, Reflections, Engagement, Survey Insights, Tutor, and Lunch & Learns — each loading data on demand to keep the interface fast even with large cohorts.
Student Roster Management
Full student roster with enrollment state, track assignments, and quick actions. Admins can view, edit, and manage any student's program participation.
Submission Review
Browse, filter, and review all student project submissions by track or student. Admins see prompt responses, file attachments, and submission timestamps in one view.
Reflection Review
View all weekly reflections with filtering by track and student. Helps instructors gauge cohort sentiment and identify students who may need additional support.
Survey Insights & CSV Export
Survey response counts and data are visualized directly in the admin panel. Both authenticated and public survey data can be exported to CSV for further analysis.
Tutor Interaction Tracking
Admins can view all AI tutor interactions and message counts per student — helping identify who is using the tool and who might benefit from encouragement.
Lunch & Learn Management
Admins can add, edit, and manage recorded office hours and Lunch & Learn sessions — including title, presenter, description, recorded date, and recording URL.
Cross-Program Admin
Super-admins on Catalyst see aggregated data across ATG, Forge, and Forte simultaneously — enabling organization-wide oversight from a single login.
Engagement Scoring Dashboard
Per-student engagement scores with a full breakdown by pillar — showing exactly where each student is thriving and where they may be falling behind.
06
Platform Architecture

Multi-Program Architecture

BCC Academy isn't a single program — it's a platform. Four distinct programs run under one roof, each fully branded, independently configured, and united under the Catalyst umbrella.

Per-Program Branding
Each program has its own logo, color palette, tagline, SEO metadata, and optional Google Analytics integration — fully customizable without touching code.
Custom Domain Support
Programs operate on their own domain or subdomain. Legacy subdomains (atg, forge, forte) automatically redirect to the correct program with session context preserved.
Cohort Configuration
Each program defines its own cohort — including display name, start date, and total weeks — allowing multiple programs to run on independent schedules simultaneously.
COPPA Compliance Controls
Programs serving minors can enable COPPA-specific requirements at the program level, ensuring the platform meets child privacy regulations for applicable cohorts.
Invite Link Enrollment
Programs can require a track-specific invite link at signup, enabling controlled enrollment into specific pathways without exposing all tracks to every registrant.
Marketing vs. App Detection
The platform intelligently detects whether an incoming visitor should see the marketing landing page or the authenticated app — based on host headers — with no manual routing configuration needed.
07
Trust & Safety

Security & Access Control

Student data is isolated by program, all access is role-gated, and the platform is built on enterprise-grade infrastructure — so the team can operate with confidence.

Role-Based Access Control
Four distinct roles — Student, Instructor, Admin, and Super-Admin — with granular permissions at every layer. Admin features are never exposed to student accounts.
Program-Scoped Data Isolation
Students, attendance records, and enrollment data are strictly scoped to a student's program. Admins can only see data from their own program — even on shared infrastructure.
Supabase Auth Foundation
Authentication is powered by Supabase Auth, providing secure email-based login, session management, and token handling without any custom credential storage.
Admin Action Audit Trail
Attendance records capture who marked them and when. Administrative actions are logged, creating accountability and a clear history of changes to student data.
Input Validation & Sanitization
All user-supplied identifiers are validated server-side with strict format rules — preventing injection attacks and malformed data from reaching the database.
Performance & Caching
Static and semi-dynamic pages use Incremental Static Regeneration (ISR), and the admin panel uses tab-gated data fetching — keeping the platform fast as cohort sizes grow.
