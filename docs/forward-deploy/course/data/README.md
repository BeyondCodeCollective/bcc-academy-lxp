# Practice data (all synthetic)

Everything in this folder is **made up**. The scenario is a youth center only
because you need one concrete example; the loop is the same in any industry.
See `OTHER_INDUSTRIES.md` for yours. No real people. Names, phone numbers and emails are fictional. Use it freely in every
exercise; it exists so you can see real output in minute one without touching
anything sensitive.

The scenario: **Riverbend Youth Center**, a fictional youth-serving nonprofit.
Enrollment requests for after-school, teen and summer programs arrive by email
from parents, school counselors and staff. A coordinator retypes each one into a
spreadsheet exported from a 2009 system, checks eligibility against rules that
live in one veteran's head (Denise), and sends a confirmation. About 20 minutes
per request, 40-odd senders, forwarded threads everywhere.

| File | Used in | What it is |
|---|---|---|
| `usage_report.csv` | Session 1 | Adoption numbers for the "Family Portal" that launched last year |
| `job_posts/` | Session 2 | Six short job adverts to sort (which one is the FDE?) |
| `discovery_transcript.md` | Session 3 | A 12-minute conversation with Denise about how enrollment really works |
| `enrollment_export.csv` | Sessions 4–9 | The 2009 system's export. Cryptic columns, mixed dates, duplicates |
| `attendance_export.csv` | Session 5 | A second system that disagrees with the first |
| `requests.md` | Session 5 | The program director's wishlist. Some of it eats a quarter |
| `intake_emails/` | Sessions 6–9 | Eight enrollment emails, from clean to chaotic |
| `program_rules.md` | Session 7 | Denise's rules, written down for the first time |
| `eval_cases.csv` | Session 9 | Twenty starter test cases with expected decisions |
| `OTHER_INDUSTRIES.md` | Setup, every session | The same loop in ten industries; find your row |

Rule for the whole course: **never paste real personal data into Claude Code.**
When you move from this data to your own workflow, use a de-identified sample
whoever owns the data has approved.
