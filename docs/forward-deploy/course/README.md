# Forward Deploy: The FDE Program

A self-paced, **hands-on** program that teaches non-technical people in **any
industry** to do the Forward Deployed Engineer job on one real workflow in their
own business or organisation:
understand the business reality, decide where intelligence belongs, build it
with Claude Code (no code written by you), make it survive failure, measure it,
ship it to a colleague, and defend it to a director. Claude Code is your
instructor and your builder.

Built on the **Forward Deploy** series and 30-day roadmap by Fonz Morris
(Beyond Code Collective): forwarddeploy.fonz.sh · YouTube: Forward Deploy.

The skill is bigger than any industry. Construction, automotive, restaurants,
hospitality, security, healthcare admin, nonprofits, retail: the loop is the
same. Requests arrive messy, someone with judgment decides, a record gets
updated. See `data/OTHER_INDUSTRIES.md` for your row.

## What you walk away with

- A working AI agent on a real workflow, **in use by a colleague**
- A one-page writeup (your portfolio piece, or your job application)
- A five-minute demo you've delivered, through the unhappy paths
- An eval report with a business number: hours saved, errors caught, days recovered
- A handover so it outlives you

## Quick start

Do `HOMEWORK.md` the night before (seven prompts, twenty minutes). Then Session
0 (install and the data rule). Then, from inside this folder
in Claude Code, say:

```
Let's get started
```

On first run the instructor asks a few quick questions, including **the one real
workflow** you'll build on. From then on every exercise runs on your workflow,
and it becomes your capstone.

Then, any time:
- **"Let's do Session X"** · **"Continue my course"** · **"Show my progress"**
- **"What's next?"** · **"I'm stuck on X"** · **"Score my capstone"**

## The 13 sessions (about an hour each)

**Start Here**
0. **Get Set Up (and Keep the Data Safe)** — install Claude Code, accept the data rule
1. **Works vs. Lands** — 41 of 11,000; why most pilots move nothing
2. **What an FDE Is (and the Four Things It Isn't)** — sort six job adverts

**Understand the Business Reality**
3. **Discovery: The Real Process, Not the Wiki Version** — 15 minutes with the person who does it
4. **Reading Someone Else's Data** — a 2009 spreadsheet with cryptic columns
5. **Decide Where Intelligence Belongs** — triage the wishlist; kill a quarter-eater

**Build It**
6. **One Model, One Platform: The Agent Loop** — email in, decision, row out
7. **Give It the Veteran's Rules** — ground it in the rules from one head
8. **Make It Survive Failure** — 20 ways it breaks; fix, fence or escalate; audit log

**Own It**
9. **Make It Measurable** — 50 eval cases; the failures are the deliverable; hours saved
10. **Ship It and Carry the Number** — in a colleague's hands; the five-deaths check

**Defend It**
11. **Defend It Like a VP** — one-pager, five-minute demo through the failures, hard questions
12. **Capstone: Publish, Demo, Hand Over** — score against the rubric

## Prerequisites

- A laptop you can install software on, and a paid Claude plan (claude.ai)
- One workflow you do or watch every week, with an owner who'll let you build on it
- Someone who'll approve a de-identified data sample (Session 4 onward); if it's your business, that's you
- About 13 hours over 5 weeks, plus 15 minutes with a colleague in week 1

## The data rule

No real personal data about customers, clients, members, employees or anyone else goes into
Claude Code during this program. The practice data is synthetic. Your own
exercises use a de-identified sample that whoever owns the data has approved.
