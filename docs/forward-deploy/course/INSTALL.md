# Forward Deploy: The FDE Program — Team Instructions

You need about 20 minutes for setup. Then the course runs itself, one hour at a time.

## Before you start
- A laptop you can install software on.
- A Claude account on a paid plan. If you don't have one, ask Fonz which plan we're using.
- Do the seven homework prompts in `5 - Pre-course Homework.pdf` the night before. Twenty minutes, on paper.

## Install (once)
1. Go to **claude.ai/download** and install the Claude desktop app. Sign in.
2. Copy the `course` folder from this package into your **Documents** folder.
3. Open the Claude app. Click the **Code** tab at the top.
4. Click **Open folder** and choose `Documents/course`.
5. In the box at the bottom, type `hello` and press Enter. If it replies, you're set.

Windows or Mac both work. If step 1 asks you to install anything else, say yes.

## Start the course
Type this in the same box:

```
Let's get started
```

It asks you a few questions, then begins Session 0. Answer in your own words.

## How every session works
- It gives you **one thing to paste**. You paste it and press Enter.
- You watch what happens and paste back what you saw.
- It explains in two or three lines, then gives you the next thing.
- About an hour per session. 13 sessions. Stop whenever you like.

## Coming back
Open the Claude app, Code tab, same folder, and type:

```
Continue my course
```

Other things you can type any time: `Show my progress` · `What's next?` · `I'm stuck on ...`

## Two rules
1. **No real personal data.** Never paste real names, phone numbers or details of members, families, donors or staff. The course ships fake practice data. When you use your own work later, it tells you how to strip names out first.
2. **You click send.** Nothing you build sends emails or changes records on its own. It drafts. You decide.

## Stuck?
Type `I'm stuck on` and describe it. If that doesn't fix it, message Fonz.

## What you're building toward
One real workflow from your own job, done the slow way today, running with an AI agent you directed, used by a colleague, with a number showing what it saved. Five weeks. Demo day at the end.
